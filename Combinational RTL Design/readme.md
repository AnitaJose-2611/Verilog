# Combinational RTL Design
This repository contains Verilog practice modules

## Modules Included
- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- EX-OR Gate
- EX-NOR Gate
- Half Adder
- Full Adder
- Half Subtractor
- Full Subtractor
- 2:1 MUX
- 4:1 MUX
- 2:1 DEMUX
- 4:2 Encoder
- 4:2 Encoder(case)
- 4:2 Priority Encoder
- 2:4 Decoder(case)
- 2:4 Decoder(enable)
- 1-bit Comparator
- 4-bit Comparator
- Ripple Carry Adder
- Carry Look-Ahead Adder
- Carry Select Adder
- Parity Generator
- Barrel Shifter
